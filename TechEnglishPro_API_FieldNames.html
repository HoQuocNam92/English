TechEnglish Pro – Tra cứu Field Name API

1. Đăng ký / Register  POST /api/v1/auth/register

FieldKiểuBắt buộcMô tả
displayNamestring✅Tên hiển thị (2–100 ký tự)
emailstring✅Chỉ chấp nhận @gmail.com
passwordstring✅6–72 ký tự

2. Đăng nhập / Login  POST /api/v1/auth/login

FieldKiểuBắt buộcMô tả
emailstring✅Email đăng ký
passwordstring✅Mật khẩu

3. Refresh Token  POST /api/v1/auth/refresh

FieldKiểuBắt buộcMô tả
refreshTokenstring✅Refresh token hiện tại

4. Đổi mật khẩu  POST /api/v1/auth/change-password  [Cần Bearer Token]

FieldKiểuBắt buộcMô tả
currentPasswordstring✅Mật khẩu hiện tại
newPasswordstring✅Mật khẩu mới (6–72 ký tự)

5. Quên mật khẩu  POST /api/v1/auth/forgot-password

FieldKiểuBắt buộcMô tả
emailstring✅Email tài khoản

6. Reset mật khẩu  POST /api/v1/auth/reset-password

FieldKiểuBắt buộcMô tả
tokenstring✅Token 64 ký tự hex từ email
newPasswordstring✅Mật khẩu mới (6–72 ký tự)

7. Tạo người dùng – Admin  POST /api/v1/users

FieldKiểuBắt buộcMô tả
emailstring✅Email
passwordstring✅Mật khẩu ≥6 ký tự
displayNamestring✅Tên hiển thị
roleCodestring❌admin / teacher / learner
phoneNumberstring❌Số điện thoại
biostring❌Giới thiệu

8. Cập nhật người dùng  PATCH /api/v1/users/:id

FieldKiểuBắt buộcMô tả
displayNamestring❌Tên hiển thị
avatarUrlstring❌URL ảnh đại diện
biostring❌Giới thiệu (≤500 ký tự)
phoneNumberstring❌Số điện thoại
statusstring❌active / inactive / suspended

9. Khóa người dùng  POST /api/v1/users/:id/suspend

FieldKiểuBắt buộcMô tả
reasonstring✅Lý do khóa (3–500 ký tự)

⚠️ Lưu ý chung

  • Base URL: https://api.techenglish.click/api/v1
  • Swagger Docs: https://api.techenglish.click/api/docs
  • Tất cả request cần xác thực phải có header: Authorization: Bearer {accessToken}
  • Email chỉ chấp nhận @gmail.com
