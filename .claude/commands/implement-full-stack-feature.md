# Implement Full-stack Feature

Implement một feature xuyên suốt:
NestJS API → Next.js Web và/hoặc React Native theo đúng requirement.

Quy trình:
1. Requirement + acceptance.
2. Domain model/rule.
3. Application use case.
4. Infrastructure/persistence.
5. NestJS presentation/API.
6. Contract.
7. Web/mobile integration.
8. UI Stitch.
9. Tests.
10. Update checklist.

Không để client tự thực hiện business rule quan trọng thuộc server.
