# Create Clean Feature

Hãy implement feature tôi yêu cầu theo Clean Architecture.

Trước khi code:
1. Đọc CLAUDE.md.
2. Đọc docs/16, 17 và tài liệu app tương ứng.
3. Xác định app: api/web/mobile.
4. Xác định domain/application/infrastructure/presentation.
5. Tìm code có thể reuse.
6. Nếu có UI, mở Stitch reference.
7. Đưa PLAN file-by-file.
8. Chờ xác nhận nếu thay đổi architecture/database lớn.

Sau khi code:
- typecheck/lint/test;
- architecture review;
- UI review nếu có;
- update checklist.
