# Review UI Against Stitch
So sánh implementation hiện tại với Stitch reference của screen.
Review theo thứ tự:
- layout/hierarchy;
- typography;
- color/token;
- spacing/radius/border/shadow;
- icons;
- responsive;
- interaction states;
- loading/error/empty.
Chỉ ra mismatch cụ thể và sửa mismatch trong scope. Không redesign.
