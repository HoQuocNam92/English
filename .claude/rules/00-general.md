# General Rules
- Trước mọi thay đổi: đọc file liên quan, không đoán code chưa xem.
- Tôn trọng conventions đang có trong repo.
- Không đổi dependency/version chỉ để tiện code nếu không cần.
- Không commit secret, token, password, `.env` thật.
- Không log password, refresh token, OTP hoặc dữ liệu nhạy cảm.
- Tất cả tên biến/code ưu tiên tiếng Anh; UI/copy theo prototype tiếng Việt.
- Tránh file quá lớn; tách module/component theo trách nhiệm.
- Không đánh dấu TODO là “done”.
