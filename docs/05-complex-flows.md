# 05 — Complex Business Flows

## Exam lifecycle
Open/start → create attempt → answer → submit → validate → grade → persist answers/results → update progress → return score + explanation.

## Progress calculation
Không là một field % nhập tay. Có thể derive từ completion, bài học, attempts, score và target certificate. Công thức cụ thể phải được chốt trong code/docs khi implement.

## AI recommendation
Input: profile, English level, interests, career/certificate goal, completed lessons, recent results, weak topics.
Output: recommended next lesson/practice + reason + priority. Service cần có contract tách biệt để thay model/provider mà không ảnh hưởng UI.
