# 14 — Seed Data Guidance

Seed phục vụ dev/demo, không phải hard-code UI.

Có thể seed:
- roles: admin, teacher, learner;
- learning levels: Beginner, Intermediate, Advanced, Professional;
- IT domains: Cloud Computing, Cybersecurity, Networking, Data Engineering, Data Science, Software Engineering, DevOps;
- sample certificates/goals;
- sample lessons/questions/exams đủ demo end-to-end.

Không dùng thông tin cá nhân thật trong seed. Dữ liệu demo phải dễ reset và không chạy nhầm vào production.
