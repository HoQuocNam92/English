## Mục tiêu sản phẩm
Hỗ trợ người học học vocabulary/technical English, đọc technical documentation/API docs/system design, học case study, luyện câu hỏi và bài kiểm tra, xem giải thích đáp án, theo dõi tiến độ và nhận gợi ý cá nhân hóa.

## Vai trò
- Admin
- Teacher
- Learner

## Lĩnh vực nội dung điển hình
Cloud Computing, Cybersecurity, Networking, Data Engineering, Data Science, Software Engineering, DevOps. Danh sách phải mở rộng bằng dữ liệu.

## Cấp độ
Beginner, Intermediate, Advanced, Professional.

Docs này phản ánh yêu cầu khóa luận. Các quyết định như framework, ORM, state manager, cloud provider là quyết định triển khai và không được tự áp đặt nếu repo chưa xác định.
