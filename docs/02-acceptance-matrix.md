# 02 — Acceptance Matrix

| Area | Required outcome | Evidence |
|---|---|---|
| Auth | Login/logout/change password + role enforcement | API tests + UI flow |
| Users | Admin/teacher can manage accounts | CRUD/search/filter UI |
| Learner profile | Store level/interests/goals | DB + profile screens |
| Content | Manage vocabulary & lessons | Web management + mobile learning |
| Question bank | Multiple categories + classification | Admin screens + DB |
| Exam | Build, take, submit, grade | End-to-end test flow |
| Result | Store history + answer review | Result/history screens |
| Progress | Derived from real completion/results | Dashboard/progress screens |
| Reports | Aggregate learner/score/progress | Report screens/API |
| AI | Personalized recommendation contract | Recommendation card/service |
| Web | Admin/teacher platform complete | Relevant Stitch screens |
| Mobile | Learner platform complete | Relevant Stitch screens |
