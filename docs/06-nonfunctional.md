# 06 — Non-functional Requirements

- Responsive web và mobile UX đúng platform.
- Accessibility cơ bản: label, focus, contrast, keyboard cho web.
- Validation cả client và server (server là authoritative).
- Pagination cho danh sách lớn.
- Avoid N+1/query thừa trong dashboard/report.
- Không leak secret/PII.
- Có logging lỗi đủ debug nhưng không chứa credential.
- Critical flow có test.
- Build/lint/typecheck phải pass trước khi xem feature hoàn chỉnh.
