# 15 — Prompt Recipes

## Bắt đầu project
`Đọc CLAUDE.md + docs. Audit repo và cho tôi plan theo roadmap. Chưa code.`

## Làm một màn hình
`Implement screen mobile_home. Bám tuyệt đối Stitch reference, dùng component hiện có và API thật. Chạy verify sau khi xong.`

## Làm end-to-end feature
`Implement question bank end-to-end từ DB/API tới admin UI theo docs và Stitch. Trước tiên đưa plan ngắn rồi thực hiện.`

## Review fidelity
`Review màn hình hiện tại với Stitch bằng ui-guardian. Sửa các mismatch layout/color/spacing/typography nhưng không redesign.`

## Tiếp tục
`Đọc checklist và repo, chọn dependency-ready task tiếp theo. Nói tôi task nào trước khi code.`
