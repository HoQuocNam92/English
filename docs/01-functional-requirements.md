# 01 — Functional Requirements

## Website Admin/Teacher
### Account & RBAC
- Quản lý learner/teacher/admin.
- Thêm, sửa, xóa/tắt, tìm kiếm.
- Phân quyền theo role.
- Login, logout, change password.

### Learner Profile
- Hồ sơ người học.
- English level.
- IT interests.
- Career goal.
- Certificate goal.
- Search/lookup.

### Learning Content
- Vocabulary chuyên ngành.
- Nội dung theo IT domain.
- CRUD + search.

### Lessons
- Technical terminology.
- Technical reading.
- Case study.
- API/technical documentation.
- Basic system design.

### Levels
- Beginner / Intermediate / Advanced / Professional.

### Certification Review Content
- Nội dung ôn tập theo domain/chủ đề/chứng chỉ.

### Question Bank
- Vocabulary.
- Reading.
- Technical Understanding.
- Scenario-based.
- Phân loại theo topic/domain/level/certificate goal.

### Tests & Assessment
- Tạo test theo topic.
- Tạo test theo certificate goal.
- Multiple choice và scenario-based.
- Auto grading.
- Quản lý kết quả learner.

### Learner Progress
- Tiến độ theo learner.
- Completion theo certificate goal.
- Nhóm learner theo career goal.
- Xem test result/score.

### Reports
- Learner count theo IT interest.
- Score theo certificate goal.
- Learning progress.
- Báo cáo quản trị.

## Mobile Learner
### Account/Profile
Register, login, edit profile, change password, chọn English level, IT interest, career goal, certificate goal.

### Learning
Vocabulary, terminology, technical article/docs, API documentation, basic system design, case study, level-based learning.

### Practice & Assessment
Practice theo IT domain; technical English question; terminology quiz; test theo topic/certificate; auto score; answer explanation.

### Progress
Personal progress, completion theo certificate goal, test history, score theo content/topic.

## AI Personalization
Recommendation phải dựa trên learner profile + goals + progress/performance. UI AI phải dùng visual treatment violet đã định nghĩa trong design system.
